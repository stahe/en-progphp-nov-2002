# Introduction to Web Programming in PHP4

🔗 Original course:
[https://stahe.github.io/en-progphp-nov-2002/](https://stahe.github.io/en-progphp-nov-2002/)

## Overview

This repository contains **course materials dedicated to web programming with PHP4**.
This is an educational document designed to support instruction and is not an exhaustive course.

The document allows students to discover the basics of web programming in PHP and provides a resource for their exercises and experiments.

## Origin of the document

This material is directly derived from the course **“Introduction to Web Programming in Java”**.
The instructional structure has been retained, but the examples and solutions have been **adapted to PHP**.

Thus, for a reader familiar with **Java and PHP**, it becomes possible to compare:

* a Java solution
* a PHP solution

for **the same web programming problem**.

## Learning Objectives

This resource aims to:
* Introduce the basics of server-side web programming
* Present concrete examples of PHP code
* Serve as a working foundation for students
* Enable an educational comparison between Java and PHP

## Notes

* This document is **course material**, not a comprehensive manual.
* Some topics are **not covered or are only briefly introduced**.
* **Further study requires the guidance of an instructor**.

Despite this, the information presented allows students to **work independently** in most cases. 

## Target Audience:

This document is primarily intended for:

* **students new to web programming**
* people wishing to **compare the Java and PHP approaches**
* learners using PHP in an educational setting
